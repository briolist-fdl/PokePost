# PokéPost public-pilot copy

## Invite description

PokéPost keeps Pokémon GO friend code channels useful instead of noisy. Players
set up one profile with their trainer code, Vivillon region and optional
Campfire name. Server admins choose the feeds and may sort regions into
Vivillon threads.

Everything available during the public pilot is free. We have not set a price or
decided on a paid plan. If that changes later, servers will get notice before
anything changes.

## Roadmap

PokéTrade posts, guided thread setup, alternative region emoji sets and more
ways to organise your Pokémon GO server are in the works. These are roadmap
items, not commands that are available yet.
