# Public copy style

Every piece of user-facing text — Discord replies, command descriptions,
invitation copy, documentation and web copy — needs a human-style editing pass
before release. Use plain, natural language and specific claims. Remove generic
product phrasing, stock transitions, artificial enthusiasm and anything that
reads as machine-written. Keep the message brief enough to scan in Discord.

Prefer short sentences and normal punctuation. Use colons, semicolons, hyphens
and dashes only when they make the sentence clearer. Recast the sentence when
they merely create a polished or AI-like rhythm.
